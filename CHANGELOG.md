## [0.1.0] - 2026-10-05

First version: six scenarios measured in process, and one that runs a real agent over a socket.

### Added
- A fake provider implementing `Upstream`, with behaviours (ok with usage, any status, request
  never sent, request sent with no answer, streaming) and call counting.
- Scenarios: the cap holding before the spend, a provider error failing over, a client error not
  failing over, a request that may already have been executed not being retried, money exact at
  1-in-1000 metric sampling, streaming not accumulated in memory.
- Scenario 7: a real `agentloop` run over HTTP through the gateway to a fake provider, with the
  reconciliation of the two independent accountings of the same run.
- `reports/latest.md` and `reports/latest.json`, regenerated by `make lab` and committed: the
  numbers are the artifact, not a claim.
- A CI gate that fails when the two accountings disagree or the agent's own trace does not replay
  identically.

### Notes
- No network to the outside: the provider is a fake server on an ephemeral port.
- Scenario 7 shells out to `tsx` and is skipped, loudly, when the `agentloop` checkout is absent.
